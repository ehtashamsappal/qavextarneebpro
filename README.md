# Qavex Tarneeb Pro

Qavex Tarneeb Pro calls trump in a Levantine majlis. Layal the oud player, Karim the calligrapher and Nadia the astronomer bid 7 to 13 tricks and defend their contracts across 8 fully implemented modes.

- Package: `com.qavex.qavextarneebpro`
- Paid, fully offline casual game by QAVEX (muhammad ehtasham).
- Zero ads, zero trackers. One optional "Buy Me a Coffee" IAP.

## Modes
- **Classic**: The pure game, no timer.
- **Timed Run**: Beat the clock for bonus points.
- **Daily Challenge**: One seeded deal per day. Streaks pay bonus.
- **Zen Table**: No timer, no pressure. Free hints and undo.
- **Kids Mode**: Gentle guidance and extra help.
- **Practice**: Learn with auto-hints.
- **AI Ladder**: Climb Easy to Expert across 8 rungs.
- **Tournament**: 5 rounds, highest total wins.
